# Académie Nova IA

Site professionnel de vente de produits digitaux (formations, ebooks, abonnements) sur l'Intelligence Artificielle.

## Stack
- HTML + Tailwind CSS (CDN)
- Design moderne, responsive, glassmorphism

## Déploiement
Ce site est prêt à être déployé sur Netlify.

Pour déployer manuellement :
1. Connecter le repo GitHub à Netlify
2. Ou utiliser le CLI Netlify

## Prochaines étapes pour revenus en boucle
1. Créer les produits dans Stripe (Checkout Sessions ou Payment Links)
2. Remplacer les liens "#" par les URLs Stripe
3. Ajouter un vrai contenu de formation (PDFs, vidéos)
4. Mettre en place un système d'accès membres (Memberstack, Outseta, ou custom avec Stripe + Supabase)

## Contenu des formations (à développer)
Les formations sont structurées de manière professionnelle pour justifier le prix :
- Modules clairs
- Exercices pratiques
- Ressources téléchargeables
- Mises à jour continues via l'abonnement
